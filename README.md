
### Проект представляет собой консольное Python-приложение для автоматизации учета результатов промежуточной аттестации студентов с использованием СУБД SQLite и архитектурного шаблона многослойного приложения (Layered Architecture).

## Описание предметной области

Система предназначена для работы сотрудника деканата / учебного отдела и позволяет:
* Находить и просматривать списки студентов, их группы и зачетные книжки.
* Учитывать и регистрировать результаты экзаменационных сессий и пересдач.
* Безопасно разграничивать доступ к операциям на основе ролей пользователей системы.

## Архитектура приложения

Проект построен по принципу разделения ответственности (Separation of Concerns) и состоит из четырех независимых слоев:

1. **`models/` (Слой моделей данных):**
   * Содержит классы на основе `@dataclass` (`User`, `Student`, `ExamResult`, `Group`, `Discipline`).
   * Преобразует кортежи из базы данных SQLite в объекты Python с явной типизацией и вычисляемыми полями.

2. **`repositories/` (Слой доступа к данным):**
   * Отвечает за выполнение SQL-запросов (CRUD-операции) через модуль `sqlite3`.
   * Содержит `user_repository`, `student_repository`, `exam_repository` и др.
   * Исключает хранение SQL-запросов в бизнес-логике и интерфейсе.

3. **`services/` (Слой бизнес-логики):**
   * Выполняет валидацию данных (проверка диапазонов оценок 2–5, заполненость обязательных полей).
   * Координирует работу нескольких репозиториев.
   * Выполняет авторизацию и проверку существования сущностей перед записью.

4. **`ui/` (Слой пользовательского интерфейса):**
   * Консольное меню (`main_menu.py`) и форма авторизации (`auth_ui.py`).
   * Перехватывает ошибки и исключения (`try-except`), исключая аварийное завершение программы.
   * Проверяет роль авторизованного пользователя перед предоставлением доступа к операциям записи.

## Схема базы данных (ER-диаграмма)

Основные сущности базы данных:
* **`UserRole`** — роли пользователей системы.
* **`User`** — сотрудники системы, заходящие под логином и паролем (администратор, сотрудника деканата).
* **`Group`** — учебные группы студентов.
* **`Student`** — студенты (ФИО, зачетная книжка, дата рождения, ссылка на группу).
* **`Discipline`** — учебные дисциплины.
* **`ExamResult`** — оценки за экзамены, связывающие студента и дисциплину.
